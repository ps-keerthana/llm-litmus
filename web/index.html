About LLM Litmus

An industry-style RAG evaluation meta-framework built around a single engineering principle: evaluate the evaluator. It measures how trustworthy each automatic grading method is against human-labeled ground truth using statistical tools — Cohen's κ, bootstrap confidence intervals, McNemar's test, and PSI drift monitoring.

8-Phase Pipeline Architecture

01

Data Pipeline

Schema validation, versioning, reproducible train/test splits — 30 tests

02

Human Labeling

CSV export + Streamlit annotation app for ground truth calibration — 18 tests

03

Perturbations

7 deliberate degradation types: paraphrase, negate, inject noise, truncate… — 29 tests

04

Four Graders

Similarity, Heuristic, NLI, and 70B LLM Judge — 4 full implementations — 35 tests

05

Meta-Evaluation Statistics

Confusion matrix, Cohen's κ, Spearman ρ, bootstrap CI, McNemar's test — 22 tests

06

Retrieval & RAG Quality

BM25 retriever, Hit@K, MRR, nDCG@K, Mean Average Precision (MAP) — 21 tests

07

CI Quality Gate

Pass/fail gate + Population Stability Index (PSI) drift detection — 15 tests

08

HTML & Telemetry Reports

Automated standalone report generator with statistical metrics — 10 tests
