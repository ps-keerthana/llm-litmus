About LLM Litmus

An industry-style RAG evaluation meta-framework built around a single idea: evaluate the evaluator. It measures how trustworthy each automatic grading method is against human-labeled data, using proper statistical tools — Cohen's κ, bootstrap CI, McNemar's test, PSI drift detection.

8-Phase Pipeline

1

Data Pipeline

Schema validation, versioning, reproducible train/test splits — 30 tests

2

Human Labeling

CSV export + Streamlit annotation app for ground truth — 18 tests

3

Perturbations

7 deliberate degradation types: paraphrase, negate, inject noise, truncate… — 29 tests

4

Graders

Similarity, Heuristic, NLI and LLM Judge — 4 full implementations — 35 tests

5

Meta-Evaluation

Confusion matrix, Cohen's κ, Spearman ρ, bootstrap CI, McNemar's test — 22 tests

6

Retrieval & RAG

BM25 retriever, Hit@K, MRR, nDCG@K, MAP — 21 tests

7

CI Quality Gate

Pass/fail gate + PSI & Wasserstein drift detection — 15 tests

8

HTML Report

Automated report generator with full stats + this dashboard — 10 tests
