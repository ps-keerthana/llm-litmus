Differentiated Feature

The auto-gate that replaces manual eval setup

Four signals must ALL agree for an auto-pass. LangSmith and Braintrust require manual evaluator configuration. This is built-in and runs on every commit.

Signal 01
Semantic Similarity
≥ 0.85

Cosine distance between embeddings of generated answer and ground truth. Measures overall meaning alignment in vector representation space.

Catches: surface-level structural changes that preserve intent — "the penalty is up to $50,000" vs "liquidated damages of $50,000."

NDA Breach — Section 4
semantic_sim: 0.934  →  PASS
Signal 02
Token F1
≥ 0.60

Bag-of-words F1 overlap after stopword filtering. Measures lexical vocabulary precision independent of embedding vector distance.

Catches: numeric substitutions that fool vector cosine — "$50,000" vs "$500,000" can score high on semantic similarity (`0.881`) but fails Token F1 (`0.420`).

NDA Trap — $500,000 substitution
token_f1: 0.420 < 0.60  →  FAIL (BLOCKED)
Signal 03
Numeric Consistency
exact match

Extracts all numeric claims (currency, percentages, section IDs, counts) from the ground truth using regex with Indian currency support, verifying each appears in the answer.

Catches: wrong tax rates (15% vs 10%), wrong section limits (₹3L vs ₹1.5L), wrong entitlement weeks (12 vs 16).

Prompt Injection — Section 80C
Injected ₹3L vs Ground Truth ₹1.5L  →  FAIL (BLOCKED)
Signal 04
Negation Detection
no flip

Detects polarity flips between reference claims and model outputs — where the model negates the core factual assertion.

Catches: "HRA deduction can be claimed" vs "HRA deduction cannot be claimed" — polar opposites that score high on cosine distance.

HRA Exemption Polarity Flip
"cannot be claimed" vs GT "can"  →  FAIL (BLOCKED)
ROUTING

Auto-pass requires all 4 signals above threshold. Auto-fail fires if semantic similarity ≤ 0.25 — clearly wrong. The LLM judge (or weighted ensemble of two models) is called only in the ambiguous middle ground — routing roughly 70% of queries without any API call, reducing evaluation cost to $0.000046 per query on average.

System Architecture

Five-stage evaluation pipeline

Each stage is independently configurable via environment variables. Point it at any corpus via DOCS_FOLDER and EVAL_DOMAIN.

01 — INGEST
Document Ingestion
  • .txt, .md corpus files
  • ChromaDB persistent store
  • SHA-256 incremental indexing
  • paragraph / sentence / fixed chunking
  • batched embedding writes
02 — RETRIEVE
Vector Retrieval
  • all-MiniLM-L6-v2 embeddings
  • Top-K cosine similarity
  • Hit Rate, MRR, nDCG@K
  • Precision@K, MAP, Coverage
  • source deduplication for MAP
03 — GENERATE
LLM Generation
  • Groq (llama-3.3-70b-versatile)
  • Ollama (any local model)
  • OpenAI (gpt-4o-mini)
  • Anthropic (claude-3-5-haiku)
  • SQLite token-bucket rate limiter
04 — EVALUATE
Oracle Gate
  • semantic similarity (≥ 0.85)
  • token F1 (≥ 0.60)
  • numeric consistency (exact)
  • negation detection (no flip)
  • LLM / ensemble judge fallback
05 — GATE
CI Quality Gate
  • GitHub Actions workflow
  • pass rate threshold (≥ 70%)
  • regression vs previous run
  • PR comment report
  • metrics_history.json updated

Developer Setup

Quick start

From clone to first benchmark in under 5 minutes. Requires Python 3.11+ and a free Groq API key from console.groq.com.

Step 01
Clone & install
Creates a virtual environment and installs all dependencies.
bash
git clone https://github.com/ps-keerthana/llm-litmus.git
cd llm-eval-pipeline

python -m venv venv
# Windows:  .\venv\Scripts\activate
# macOS/Linux: source venv/bin/activate

pip install -r requirements.txt
Step 02
Add API key
Free Groq key at console.groq.com — no credit card required.
.env
GROQ_API_KEY=gsk_your_key_here

# Optional: switch provider or domain
LLM_PROVIDER=ollama          # or openai, anthropic
EVAL_DOMAIN=legal            # label for this corpus
Step 03
Run evaluation
Smoke test is 32 queries (~3 min). Full benchmark is 204 queries (~15 min).
bash
# Smoke test — 32 queries, ~3 min
python evaluate.py --smoke

# Full benchmark — 204 queries, ~15 min
python evaluate.py

# Check quality gate against thresholds
python ci_gate.py

# Analytics dashboard at localhost:8501
streamlit run dashboard/app.py
